orcas.live API

A free, read-only JSON API for which Orcas Island businesses are open right now. Use it to put an “open now” list on your own site.

Base URL
https://api.orcas.live
Format
JSON, GET requests only
Auth
None. No key needed.
CORS
Open to any origin, so you can call it from the browser
Rate limit
About 120 requests per minute per client. Responses are cached for about 20 seconds, so polling faster gains nothing.
Time zone
All times are Orcas Island local time (Pacific), without an offset

Endpoints

EndpointReturns
GET /v1/open-nowBusinesses open now, as an object grouped by area slug. Includes ones closing soon.
GET /v1/businessesEvery listed business as an array, open or not, sorted by name.
GET /v1/businesses/{id}One business. 404 if the id does not exist.
GET /v1/areasThe list of areas, with slug and display name.
GET /healthzPlain text ok when the service is up.

Filters

These query parameters work on /v1/open-now and /v1/businesses, and can be combined.

ParameterValues
areaeastsound, ferry_landing, westsound, doe_bay, deer_harbor, rosario, other
typebar, restaurant, shop, service
categoryExact category, such as pub or coffee shop (not case sensitive)
qText to find in the business name
curl "https://api.orcas.live/v1/open-now?area=eastsound&type=restaurant"

FieldMeaning
typebar, restaurant, shop or service
status.stateopen, closing_soon, opening_soon, closed or unknown
status.next_changeWhen the current window ends if open, or when the next one starts if closed. May be null.
staletrue when the owner has not confirmed the hours recently, or never. Treat the hours as a best guess.
last_confirmedWhen the owner last confirmed the hours (UTC), or null
closureSet while closed for the season, such as {"label": "May 2027", "until": "2027-05-31"}. Otherwise null.
weeklyRecurring hours. weekday is 0 for Monday through 6 for Sunday. A close time earlier than the open time means it closes after midnight. A day can have several rows. valid_from and valid_to mark seasonal hours.
recurring_eventsWeekly events such as trivia. start and end may be null when the time is unknown. Check valid_from and valid_to for seasonal ones.
eventsUpcoming one-time events, soonest first. start is null for an all-day event.
lat, lng, phone, website, menu_url, addressMay be null. Phone numbers are in E.164 format.

Embed example

<ul id="open"></ul>
<script>
fetch("https://api.orcas.live/v1/open-now?area=eastsound")
  .then(r => r.json())
  .then(byArea => {
    const list = document.getElementById("open");
    for (const b of Object.values(byArea).flat()) {
      const li = document.createElement("li");
      li.textContent = b.name;
      list.append(li);
    }
  });
</script>
